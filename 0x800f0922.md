Windows 11 Update 0x800f0922.md

- go to HKLM\software\microsoft\windows\currentversion\winevt\channels, and delete "Microsoft-Windows-Store/Operational". Might be a good idea to save/export the key first, so you have a backup.
- go to HKLM\software\microsoft\windows\currentversion\winevt\publishers and delete "{53e3d721-2aa0-4743-b2db-299d872b8e3d}".
- Reboot and retry the update.


Mai 2026: KB5089549 - neue Mögliche Ursachen
- Im Log C:\Windows\Logs\CBS\CBS.log nachschauen
    - "SpaceCheck: Unzureichender freier Speicherplatz"
    - "ServicingBootFiles fehlgeschlagen. Fehler = 0x70"
    - "SpaceCheck: <Wert> wird von Dateien von Drittanbietern/OEMs außerhalb der Microsoft-Startverzeichnisse verwendet"  
- Volle EFI Partition
- Microsoft Registry Hilfe, soll wohl den Fehler beseitigen
    - reg add "HKLM\SYSTEM\CurrentControlSet\Control\Bfsvc" /v EspPaddingPercent /t REG_DWORD /d 0 /f
- Die EFI Partition vergrößern
